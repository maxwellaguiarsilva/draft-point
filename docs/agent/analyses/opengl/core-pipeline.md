# Core pipeline

## Objective

Define the `core-pipeline` tier as the union of pipeline-driven operation groups: the modern, state-of-the-art Core profile surface not captured by `direct-state-access`, contributing to the derived `canonical` union.

## Nodes

- [draw-execution](draw-execution.md) — pipeline-driven draw execution operation group.
- `rasterization-state` — rasterization state operation group.
- `synchronization` — synchronization operation group.
- `shader-pipeline` — shader pipeline operation group.
- `query-measurement` — query and measurement operation group.
